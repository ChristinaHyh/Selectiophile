隐私政策

生效日期：2026 年 11 月 12 日

Selectiophile（原名 Lectiophile）是用于网页划线、评论和剪藏的浏览器扩展，可将内容保存到你选择的本地 Obsidian 文件夹。插件没有开发者运营的服务器；开发者不接收你的笔记和浏览内容。

保存在本地的数据

笔记、评论及剪藏原文以 Markdown 文件保存在你指定的文件夹。插件会读取该文件夹中的笔记，以识别和定位内容。

设置、高亮信息、网页与笔记的关联、模板及 Jev API Key 保存在浏览器扩展存储（chrome.storage.local）；文件夹访问句柄保存在 IndexedDB。API Key 在本地保存时未单独加密，且不会包含在导出的备份中。

可选的 AI 数据处理

只有在你提供 Jev API Key 并使用 AI 归类功能时，插件才向 TypeSafe AI（Jev） 发送归类所需的信息，包括划线、评论、相关段落、来源标题或网址，以及候选笔记的标题和小标题。首次处理 AI 对话时，还可能发送你在设置中允许的前几轮对话（设为 0 可关闭）。API Key 用于请求认证。

这些信息由 TypeSafe AI 按其政策处理。没有 API Key 时，插件不向 Jev 发送内容；网页剪藏也不会发送给 Jev。

数据控制与使用范围

  • 你可以选择启用的网站、关闭 AI 对话上下文，或不使用 Jev。
  • 卸载扩展会清除其浏览器本地存储；已写入 Obsidian 文件夹的文件需由你自行管理。
  • 插件不提供广告或使用分析，也不收集完整浏览历史或出售用户数据。

更新与联系

政策变更将发布在此页面并更新日期。如有疑问，请通过 GitHub 项目仓库 联系开发者。

Privacy Policy

Effective November 12, 2026

Selectiophile (formerly Lectiophile) is a browser extension for highlighting, commenting on, and clipping web pages into an Obsidian folder you choose. The extension has no developer-operated server. The developer does not receive your notes or browsing content.

Data stored locally

Notes, comments, and clipped pages are saved as Markdown files in your selected folder. The extension reads notes in that folder to locate related content.

Settings, highlights, page-to-note associations, templates, and your Jev API key are stored in chrome.storage.local. IndexedDB stores your folder access handle. The API key is not separately encrypted in local storage and is excluded from exported backups.

Optional AI processing

Only when you supply a Jev API key and use AI filing does the extension send necessary context to TypeSafe AI (Jev): highlighted text, comments, surrounding passages, source titles or URLs, and candidate note titles and headings. For the first highlight in an AI conversation, it may also send the initial turns allowed by your settings (set this to 0 to disable). Your API key authenticates the request.

TypeSafe AI processes that information under its own policies. Without an API key, no content is sent to Jev. Page clipping does not send content to Jev.

Your control and our practices

  • Choose which sites are enabled, disable AI conversation context, or use the extension without Jev.
  • Uninstalling clears the extension's local browser storage. Files already saved to your Obsidian folder remain yours to manage.
  • We do not use ads or analytics, collect your full browsing history, or sell user data.

Updates and contact

Changes to this policy will be reflected here with a revised date. For questions, contact the developer through the GitHub repository.
